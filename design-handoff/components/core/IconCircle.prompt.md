Swifto's most repeated motif — a pale primary/10 disc with a brand-blue stroke icon inside. Anchors trust-strip items, how-it-works steps, and dashboard tiles. The icon inherits `currentColor`.

```jsx
<IconCircle>
  <svg width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" strokeWidth="2"><path d="M9 12l2 2 4-4…"/></svg>
</IconCircle>
<IconCircle size="lg" />        {/* 80px dashboard tile */}
<IconCircle tone="onBrand" />   {/* white-on-blue band */}
```

Sizes: sm 40px, md 48px, lg 80px. Icons follow the Heroicons outline style (2px stroke).
