Swifto status pill — tiny rounded-full label for job and application states.

```jsx
<Badge tone="success">Applied</Badge>
<Badge tone="warning">Urgent rebook</Badge>
<Badge tone="brand">Verified</Badge>
```

Tones: `neutral`, `brand`, `success` (green — applied/complete), `warning` (amber — urgent rebook), `danger` (red). Add `solid` for a filled high-contrast variant.
